# Vial 键盘布局

保存了 `ZBOX v1.0.vil`、`ZBOX v1.1.vil`、`ZBOX v1.2.vil` 和 `back.vil`，源文件逐字节保留。版本号最高的是 v1.2；请按需要选择，不能据此确认键盘当前正在使用哪一份。

Windows 和 Linux 稀疏安装都会下载 shared/vial。连接匹配的键盘，在 Vial 中使用 File → Load layout 导入所选 .vil。安装脚本不会自动改写键盘，布局里的 UID 保留用于固件匹配。

四份布局的宏列表均为空。qmk_settings.json 是应用设置界面的字段定义，不是个人键盘布局；程序本体及 DLL 不收录。导入前建议先从键盘保存当前布局作为备份。
